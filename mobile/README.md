# GGS Field — the site supervisor app

Android app for site supervisors (Bastion field app, Phase 1, 29 Oct 2026).
Expo SDK 57 · React Native 0.86 · Expo Router · supabase-js.

**DECIDED (Shayan, 29 Oct 2026):** this app is field-only. The full office app
that used to live here (every Bastion page, finance included) was removed; office
staff use Bastion on the web. A supervisor's phone holds no financial data.

## What it does

1. **Sign in** with employee code + 6-digit PIN. The app turns these into the
   login `fieldEmail(code)` / `fieldPassword(code, pin)` in `src/lib/supabase.ts`,
   which must match `supabase/functions/field-account` exactly.
2. **This phone** is registered (`field_register_device`). The login's first
   phone is approved at once; a new phone waits for a super admin in
   Access & Governance › Field accounts. Every request carries this phone's id
   in `x-bastion-device`; the API gate refuses an unapproved phone.
3. **Sites** (`field_me`) and each site's **guards** (`field_site_roster`): name,
   code, shift, phone (tap to call) and expiry flags. No CNIC numbers, no pay.
4. **Sessions last 14 hours** from sign-in (0608). The app shows "Signed in
   until…", warns in the last 30 minutes, and signs out at the mark.

Everything a supervisor can reach is enforced by `api_request_gate` (0607):
a supervisor login can call `/rpc/field_*` and nothing else, whatever this app does.

## Build

GitHub Actions (`.github/workflows/field-app.yml`) builds a signed APK on every
push to `mobile/` and on demand (Actions › Field app APK › Run workflow). The APK
is under the run's Artifacts. The signing key is three repository secrets — see
the workflow header. `android/` is generated by `expo prebuild`; never edit it.

```bash
npm install
npm run typecheck
npm run lint
```

Photos: a guard with `has_photo` gets their photo from `field_guard_photo(site, guard)`
(0609), one call per guard, kept for the session; tap it to see it full size.
Without the function, or without a photo, the row shows initials.
